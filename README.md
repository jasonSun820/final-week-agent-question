# Final Week Survival System

Static PMF validation landing page for a Final Week Survival System waitlist.

## Deploy to Vercel

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Go to https://vercel.com/new.
4. Import the GitHub repository.
5. Framework Preset: `Other`
6. Build Command: leave empty
7. Output Directory: leave empty
8. Click Deploy.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open repository Settings.
3. Go to Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/root`.
6. Save.

## Files

- `index.html`: complete static website.
- `.nojekyll`: makes GitHub Pages serve files as-is.

## Notes

This version is optimized for mobile-first PMF validation with Chinese international students. It includes:

- Waitlist form
- Founding beta screening
- Live survival score
- Final Week profile tags
- Mobile sticky CTA
- Copyable invite text
